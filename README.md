# Kinetic Anatomy

Interactive 3D anatomy and physiology learning through martial arts stances.

Start here:
- `AGENTS.md`: rules for the AI coding agent
- `TASKBOARD.md`: what to build, in order
- `docs/PRD.md`: what the product is and who it is for
- `docs/TECH_STACK.md`: every tool and why
- `docs/ARCHITECTURE.md`: how the pieces connect
- `docs/DATABASE.md`: tables and security rules
- `docs/3D_GUIDE.md`: how the 3D body and poses work
- `docs/CONTENT_GUIDE.md`: anatomy content standards and seed data
- `docs/SECURITY.md`: security checklist
- `docs/DEPLOYMENT.md`: how to go live on Vercel

## Run locally

```
npm install
cp .env.example .env.local   # then fill in your Supabase keys
npm run dev
```
